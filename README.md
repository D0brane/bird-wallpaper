# 鸟群与隼

Windows 10 和 Windows 11 的动态壁纸，不是只支持 Windows 11。画面是一群按局部规则飞行的鸟。鼠标和桌面图标是两种看不见的隼，鸟会躲开它们。鸟飞出屏幕后从对面回来。隼本身不画出来，系统鼠标也不会被藏起来。

壁纸用 [Lively Wallpaper](https://github.com/rocksdanister/lively) 播放。页面会铺满当前屏幕，背景按 cover 缩放。这套壁纸按 Windows 11 制作，目前只在 Windows 11 上测试过。Windows 10 如果没有 winget，请先自行安装 Lively Wallpaper，再运行下面的安装脚本。

## 演示

[桌面录屏](demo/desktop.mp4) 是在 Windows 11 上录的。这段视频只放在仓库里，安装脚本不会把它复制到壁纸目录。

## 一键安装

在 PowerShell 里运行：

```powershell
irm https://raw.githubusercontent.com/D0brane/bird-wallpaper/main/install.ps1 | iex
```

也可以下载本仓库后双击 `install.bat`。

脚本会做这些事：

1. 如果找不到 Lively，用 winget 安装 `rocksdanister.LivelyWallpaper`。没有 winget 时脚本会停下，并说明需要先自行安装 Lively。
2. 把壁纸复制到 `%LOCALAPPDATA%\BirdWallpaper`。仓库里的 `params.json` 会一起复制，所以新安装从这套调好的参数开始。
3. 登记登录计划任务 `BirdWallpaperIconProbe`。登录后延迟 30 秒，用 64 位 PowerShell 在后台启动 `icon-probe.ps1`。
4. 立刻启动一次图标探测，并用 Lively 把这个目录设为当前壁纸。

如果桌面没有立刻换上，打开一次 Lively Wallpaper，再双击 `install.bat`。

## 桌面上能做什么

右上角是「设置」。收起后只剩一条小条，点「展开」打开。设置栏限制在任务栏上方，列表太长时点滚动条上下箭头即可。

可以调这些参数：

| 参数 | 作用 | 初始值 |
| --- | --- | --- |
| 分离 | 推开过近的邻居 | 1.4 |
| 对齐 | 转向邻居的平均方向 | 1.1 |
| 聚集 | 靠向邻居的平均位置 | 0.6 |
| 躲避 | 躲开鼠标这只隼的强度 | 2.4 |
| 感知半径 | 一只鸟能看见邻居的距离 | 103 |
| 鼠标威胁半径 | 超出后鼠标不再影响鸟 | 168 |
| 鼠标躲避阈值 | 这个距离内对鼠标的躲避拉满 | 47 |
| 图标威胁半径 | 超出后图标不再影响鸟 | 57 |
| 图标躲避阈值 | 这个距离内对图标的躲避拉满 | 65 |
| 图标躲避 | 躲开图标这只隼的强度 | 1.5 |
| 最大速度 | 鸟的速度上限 | 208 |
| 数量 | 鸟的只数，范围 20 到 450 | 415 |
| 鸟的大小 | 显示尺寸，范围 6 到 64 | 22 |
| 受力滤波 | 越大转向越跟手，越小越稳 | 48 |
| 位置滤波 | 越大画面越贴真实位置，越小越不抖 | 48 |
| 朝向滤波 | 越大鸟头转得越快 | 18 |
| 受惊滤波 | 越大变色越快 | 48 |

滤波范围都是 1 到 48。暂停只停物理计算，画面还在。重置会按当前数量重新散布鸟群，不把参数改回旧值。

鸟群图案和背景从列表里选。留空时鸟是程序画的折线，背景是程序画的夜空。仓库自带四款简约鸟标（光刃、尖箭、菱镖、双翼）和五张夜空照片（银河、极光、月夜、星云、地平微光）。也可以从本机选一张图，这次选择只在当前这一次播放里有效。要让新图在重启后还在，把图片放进安装目录的 `birds` 或 `backgrounds`。图标探测下次扫描时会更新 `list.json`。

状态行显示当前有多少只鸟处于明显受惊（受惊程度超过 0.25）。

## 鸟群怎么飞

每只鸟只根据附近的邻居和两只隼决定下一步，没有全局指挥。这是 Craig Reynolds 的 Boids，再加躲避。

每一帧对每只鸟做这些事：

1. 用空间网格找感知半径里的邻居。网格按屏幕环绕复制了边缘上的鸟，所以一只鸟也能看见从对面绕过来的邻居。邻居距离取穿过屏幕边缘后更短的那一段。
2. 分离：在更小的一圈里把过近的鸟推开。这一圈不是单独的滑条，而是感知半径的 0.46 倍，并限制在 16 到 34 之间。越近推力越大。
3. 对齐：转向这些邻居的平均速度。邻居几乎停着时不产生对齐。
4. 聚集：朝这些邻居的平均位置靠。位置同样按环绕后的短距离计算。
5. 躲避鼠标：指针在画面内时，鼠标是一只强度为 1 的隼。距离小于等于躲避阈值时害怕拉满，从阈值到威胁半径线性降到 0，再远就没有影响。鼠标移动较快时，鸟躲的是指针前方最多 0.45 秒的预测点。指针离开画面后，这只隼的影响大约在 0.8 秒内消退。
6. 躲避图标：每只鸟只躲离它最近的那一个图标。阈值和威胁半径与鼠标分开。图标位置同样可以穿过屏幕边缘影响另一边。
7. 把五股力按各自的强度相加，并限制总力的大小。受力先经过低通滤波，再改变速度。受惊时速度上限最多再提高 22%。
8. 位置按速度前进，超出屏幕就从对面进来。画在画面上的位置、朝向和变色再各自做一次低通滤波，所以物理位置可以及时改，画面不会跟着高频抖动。滤波混合量是 `1 - exp(-帧间隔 × 滤波值)`，数值越大越跟手。

折线鸟受惊时，填充色向 `rgb(255, 168, 96)` 混合。使用图片时，先在离屏画布上把图案染成同一颜色，再按受惊程度叠到原图上。这样变红的是鸟，不是整块背景。

## 图标位置怎么来

壁纸页面读不到桌面图标。`icon-probe.ps1` 在系统里读，再把坐标写成 `icons.json`。

它找到资源管理器里真正的桌面列表（`Progman` 或 `WorkerW` 下面的 `SysListView32`），用 `LVM_GETITEMRECT` 取每个图标矩形的中心。坐标先加上虚拟屏幕原点，再按 DPI 换成 CSS 像素。页面读到之后减去自己窗口的 `screenX` 和 `screenY`，得到壁纸里的位置。文件里只有坐标，没有图标名字。

探测大约每 1.5 秒读一次，但只在三件事同时成立时才读：桌面列表还在、当前输入桌面可以打开（没有锁在登录或安全桌面）、Lively 的 WebView2 或 CefSharp 播放器正在运行。否则它睡 5 秒。位置签名没变时不重写文件。同一时刻只允许一个探测进程，互斥名是 `Local\BirdWallpaperIconProbe`。

页面也大约每 1.5 秒重新读取 `icons.json`。Lively 暂停壁纸或页面隐藏时，动画循环停掉，读取也跟着停。

## 参数怎么记住

壁纸页面不能直接写磁盘，而且 Lively 每次加载都可能换一个临时浏览器目录，所以不能靠 localStorage。

改任何参数后，页面把数值和当前选中的图片文件名 POST 到 `http://127.0.0.1:8766/params`。这个端口只绑在本机回环地址上。探测进程收到后，按 `LivelyProperties.json` 里的最小、最大和步长检查数值，图片名必须是安全的文件名，然后把 `params.json` 写到带有 `bird-wallpaper.marker` 的壁纸目录。请求体最大 8 KB。同时把当前鸟标、当前背景，以及 `birds`、`backgrounds` 里的文件名写入 `assets.yaml`。鸟标留空表示折线，背景留空表示夜空。

下次打开时，页面先读 `params.json`。文件存在就用文件里的值，并在 5 秒内忽略 Lively 推过来的旧属性，避免把调好的参数盖掉。没有文件时，才使用 Lively 属性或页面上的初始值。

`icons.json` 只留在本机，不在仓库里。探测进程不向外网发送桌面数据。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html`、`style.css` | 画面和设置栏 |
| `sim.js` | 鸟群、躲避、滤波、存读参数 |
| `LivelyInfo.json` | 告诉 Lively 这是网页壁纸，并接收暂停事件 |
| `LivelyProperties.json` | Lively 属性定义，也是参数的取值范围 |
| `params.json` | 初始参数；安装后继续被本机修改覆盖 |
| `assets.yaml` | 当前使用的鸟标和背景，以及可选文件名 |
| `icon-probe.ps1` | 读图标位置，并在本机接收参数保存 |
| `install.ps1`、`install.bat` | 安装壁纸、播放器和计划任务 |
| `install-probe.ps1` | 只登记登录计划任务 |
| `birds`、`backgrounds` | 可选图案和背景，各有一份 `list.json` |
| `demo/desktop.mp4` | 桌面演示录屏，不参与安装 |
